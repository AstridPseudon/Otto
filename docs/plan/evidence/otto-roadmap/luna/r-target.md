### Stress-test findings

The clearest seams are already present: native turn completion in both host adapters, a single owner execution admission boundary, durable due records, and commit-specific worker checking. The biggest gaps are **event-driven wake-up**, **independent liveness monitoring**, and **a general message abstraction**. The last is not just renaming: current issue/help/advisor paths carry distinct authority, routing, and retained-effect logic, so consolidation needs to preserve those semantics.

Dollar enforcement is a particular design risk: current usage code can price qualified observations when model, attribution, timestamp, and rate data exist, but missing facts remain unavailable, and Codex’s selected usage schema reports no money (`src/herzchen/usage/contract.py:120–151`; `src/herzchen/usage/accounting.py:154–165`). A post-run estimate alone cannot guarantee an owner-set spend ceiling.
