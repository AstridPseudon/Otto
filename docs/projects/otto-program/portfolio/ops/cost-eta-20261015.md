## What drives the cost
1. **The orchestrator.** Opus with a huge context is about two-thirds of the spend so far: each call re-reads about 400k tokens. A fresh orchestrator session with a short brief would cut this 3–5×.
2. **Long Sonnet contexts.** 63 of HOSTKIT's 110 calls ran with more than 200k tokens of context. Tighter briefs and smaller tasks would help.
3. **Turns lost to permissions.** GREEN took 179 turns partly because shell loops were refused, so it ran each file as a separate call.
4. **Stops and restarts** (the disk stop): modest; resumes reuse the conversation.

Small sample: seven tasks, mostly early and self-contained. Re-estimate after SKEL0.
