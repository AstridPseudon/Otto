# Existing shared owner installation

An installation with `owner_composition.kind = shared-project-services` runs the pinned existing supervisor wrapper. It cannot select the standalone fresh-install Store opener. `ProjectOwnerService` borrows the already open Store and existing fixed `ProjectServices` views; host lanes are polled on that host's serialized owner lane. Existing projects keep their activation state, manager occurrences, Evidence capability, budgets and supervision. New host projects remain pending until a closed owner composition admits a fixed view.

The human-authorized production ceiling is three active manager turns, two productive workers and three native transports in total. These ceilings apply together. Same-session turns remain serial and each checkout has one writer. An uncertain original occurrence keeps its capacity hold. Admission of a Claude host creates its own principal and portfolio; `whoami` and `effective-context` are provider-free reads. Receipt mailbox delivery is inspectable, not unattended desktop push. The existing Astrid chat's separate scoped principal remains unchanged.

Launchd wraps the same bounded supervisor, restarts unsuccessful wrapper exits and reuses its exact retained policy and exit count with `resume=True`. Normal stop, pause and exhausted restart policies exit successfully. If a supervisor crashes while its child remains alive, reconciliation holds instead of opening a second Store or replaying a provider effect. An unknown child exit remains held for exact owner reconciliation; automatic reattachment is not claimed.

The legacy combined run-bundle import remains a migration route. New planning uses one template project package, check-in and export. Existing adopted role models and final-review budgets cannot be replaced by host profile suggestions.

The old folder transport keeps its measured 16 KiB serialized-request guard. The trusted authenticated host file-lane composition explicitly admits requests up to 256 MiB; its per-operation limits remain 1,000 files / 256 MiB and 10 MiB per document. A public JSON flag cannot change this transport capability.
