## Implemented boundary

`src/otto/engineering/release_records.py` provides typed `RepositoryRecord`,
`SourceSetEntry`, `ProcessProfile`, `CommandEnvelope`, `CommandReceipt`,
`ReleaseEvent`, and `ReleaseLedger` records. The explicit commands are
candidate selection, required-check recording, manager decision, merge
observation, source promotion, package publication, and deployment. Records
persist through an explicit JSON snapshot/save/load call; construction does
not start a scheduler, queue, allowance, or release action.

Rights map: repository/candidate → `repository_owner`; checks →
`check_authority`; manager decision → `manager_authority`; merge →
`merge_authority`; source promotion → `promotion_authority`; package
publication → `publication_authority`; deployment → `deployment_authority`.
The selected installed profile was `otto-12-hour` for `manager-1`, with
`scheduler=none`, `queue=false`, `periodic_allowance=none`, and
`automatic_deployment=false`.

## Failure and recovery matrix

| Case | Typed observation | Release side effect |
|---|---|---|
| stale target head | `stale_head` | no record/promotion/publication/deployment delta |
| changed source set | `changed_source_set` | no unintended delta |
| duplicate source key | `duplicate_source_set_key` | no unintended delta |
| same logical key | `replayed` for identical payload; `replay_conflict` for changed payload | original result only; changed request has no delta |
| partial promotion | `partial`, explicit completed/pending/unknown steps | resumable by same owner only |
| unknown runner | `unknown` | no target-head change and no publication/deployment |
| no auto publication/deployment | `not_performed` | merge does not imply either operation |

Concrete unresolved gaps: this boundary records explicit runner observations;
it does not itself invoke a remote Git runner, package publisher, or live
deployment target. No successful remote merge or promotion was claimed in the
representative proof, and the accepted Herzchen wheel was installed/imported
for origin pinning but was not changed or extended. Those later integrations
remain outside OTT-05 and require their own authority and proof.
