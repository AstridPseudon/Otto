# Frame: connected Vision example

Frame has a product root with two areas: Product Experience and Platform. Its
repository descriptions cover web app, desktop app, project model, sync
service, media engine, agent runtime, and platform API. The shared `offline
access` concept applies to desktop, sync, and project model. The sync subsystem
describes a future operation journal, reconciliation boundary, and conflict
presentation. A design decision records the unresolved tension between local
availability and conflict visibility. A near-term recovery-copy task may refer
to this intent without claiming to implement the architecture.
