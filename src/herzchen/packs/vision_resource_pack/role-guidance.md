# Role guidance: Vision

## Person author

Use `vision create` for a typed node, `vision query` for the finite tree/table
views, and `vision reorganize` for a bounded rename or reparent. Cite the
received document and revision pins in design discussion. Do not treat an
aspiration as implementation or permission.

## Authenticated agent

The host binds the actor, grant, Direction, task context, and resource
selection. The request supplies no actor override. Recheck access on every
read, keep project membership separate from visibility, and disclose partial
coverage. Use `context` to answer a bounded design question and `snapshot` to
create an explicit ordinary DAT checkpoint.

## Operations and lifecycle

The finite operations are `help`, `create`, `read`, `query`, `reorganize`,
`context`, `history`, `attach`, and `snapshot`. `help` returns the exact
selected pack/resource pins and host contract. Resource upgrade is explicit;
historical definitions remain pinned or are truthfully unavailable. Disabling
guidance does not remove content, immutable revisions, or checkpoints.
