# Otto skills

This index is the concise discovery surface for maintained Otto workflows.
Use it when an app, host, agent, native session, command response, or reminder
was interrupted, is held/unknown, or must continue an existing project.

- [Recovery](recovery/SKILL.md): inspect retained state, find the existing
  project or session, resume the exact eligible occurrence, verify the next
  actor, and use authorized replacement/reassignment only after custody is
  resolved. It includes reminder continuity.
- [Adding a new agent CLI adapter](../../../../docs/manager-journey-commands.md#adding-a-new-agent-cli-adapter):
  the bounded adapter contract, trusted selection, native identity and
  result/artifact obligations for a new CLI.
- [Launch, inspect, stop and recover agents](../../../../docs/manager-journey-commands.md#launch-inspect-stop-and-recover-agents):
  the installed command recipes, stable request-key/occurrence reads,
  bounded result consumption, yield/return rules and recovery controls.
